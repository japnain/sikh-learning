# Artwork-inspired NaamRas navigation

> Evidence note: `artifacts/` links and localhost previews in this document refer to preserved local QA records, which are excluded from Git. Historical build results apply only to their named snapshots; the current session-only push scope is recorded in [pre-push readiness](../qa/session-prepush-readiness.md).

October 21, 2026. Current implementation: **v28**, replacing the owner-rejected v27 icons. Owner approval of the new direction is not assumed.

The replacement uses original 28px shapes with substantial inked planes and deliberate negative space: a courtyard facade for Home, an open pothi with a broad binding for Read, a folded manuscript ribbon for Saved, and four arched jaali panels for More. The original thin-line inserts and selected icon capsule are removed. The active underline, stronger label and brass color remain.

One composition serves both themes: warm stone and midnight slate, using existing tokens. Four destinations, readable localized labels, compact-screen bottom position, desktop rail, safe-area compensation, measured page-space reservation and immersive reader controls remain. No raster icons, glow, faux-metal effects or decorative motion were added.

The icons were inspected in actual Home/Nitnem contexts at 1× before production checks. The first replacement's ribbon was too heavy and its medallion looked like a gear; the ribbon was lightened and More became the arched grid. Independent review found no further concrete correction after those changes. This is a design comparison, not owner approval or proof of a subjective “world class” label.

The final production build passed **581 assertions across 12 fresh contexts**, five accessibility scans with zero violations, keyboard/route/reader checks and the separate 21-check real-worker/offline journey. Narrow, landscape, desktop, safe-area and enlarged Punjabi/Hindi layouts were included. No earlier navigation geometry substituted for this final matrix.

The Baseline UI skill guided focus, target sizes, safe areas and restrained interaction. The required uploaded-screen [revised Lazyweb review](https://www.lazyweb.com/report/lazyweb/f76c5d93-8ece-4cea-9821-9a70810d00c6/?source=create) completed and was opened in the default browser; this is its free preview. [Independent review](../../artifacts/navigation-20261021/independent-review.md) preserves the rejected direction and later corrections.

[Current acceptance and screenshots](../qa/artwork-navigation-acceptance.md) bind the result to v28. Browser standalone/safe-area/text-size scenes are explicit proxies, not physical Safari or VoiceOver evidence. Native signing/device gates and public deployment remain outside the owner's PWA scope.
