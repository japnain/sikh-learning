Three distinct truths

What is open, what is usual, and what was completed.

Open reading

The chooser beside a reading changes that reading, from Home or the reader. A secondary “Use for my Nitnem” action updates the usual choice. A shared link never changes it.

Usual preference

Customize edits remembered lengths with Save/Cancel. Changing a default never moves an active reading. If different, show “Reading Long · Usual Short.” No confirmation is needed each time a bani opens.

Daily practice

Credit a bani once. After Short is completed, opening Long shows “Read today · Short”; the new version is not falsely completed and the daily total does not fall.

Fresh paath is different from an old saved place.

Continue the intentional daily session; offer Begin for a fresh practice. Older Study places remain available separately. An open session survives midnight; completion is dated when explicitly recorded.

Navigation should allow exploration.

Contents and Find need Return to the reading position before replacing ordinary resume. Keep awake is an optional reading comfort setting, released when leaving the reader.

Completion should lead somewhere useful.

Complete & continue opens the next exact reading only after saving succeeds. Home promotes the next bani while keeping Undo reachable. Respect personal order; do not silently rearrange it by the clock.

Deferred: memorization line reveal

Potentially valuable, but a separate interaction requiring careful testing of text selection, accidental taps and sacred-text continuity. First improve everyday reading access, navigation and session reliability.

Reference patterns and evidence

These sources demonstrate patterns; their adaptation to NaamRas is a design proposal, not a measured outcome.

  • YouVersion: the current version abbreviation opens version selection directly.
  • Spotify: a focused current item can have a separate, accessible view of the upcoming sequence.
  • Paprika: optional Keep Screen On disables sleep while viewing a recipe and restores it after leaving. This is a useful bounded comfort pattern for long readings.
  • Project evidence: docs/design/experience-quality-plan.md records the earlier rejection of seven expanding Home rows. The current reader, Nitnem and saved-place code were inspected for the state decisions above.
Planning artifact only. Existing app code is unchanged. Validate real supported lengths, source order, saved places, offline behavior, large text, VoiceOver and sustained physical-iPhone reading before judging the result.
