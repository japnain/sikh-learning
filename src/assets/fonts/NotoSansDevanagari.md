# Noto Sans Devanagari

The unmodified variable Devanagari subset is bundled locally for consistent Hindi sharing and localized metadata. It covers weights 400–700 and is used after the existing Latin/Gurmukhi families. Shared PNGs wait for this font before measuring or drawing text; no runtime request to Google Fonts is required.
